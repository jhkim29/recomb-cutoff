This saves or reuses marginals.npy and updates this page. Q₂ is evaluated using the orthonormal expansion's quadratic kernel. The displayed example illustrates the cutoff theorem at one finite n.

  • Easy exact sampling: a comonotonic ancestor needs just one uniform U, with Xᵢ = Fᵢ⁻¹(U). At generation t, each site independently picks one of 2ᵗ ancestor labels; sites with the same label share U. This costs O(n + 2ᵗ) near the window. For 2ᵗ > 4n, only occupied labels are generated, using O(n log n) work.
  • Why comonotonic: proving cutoff—a drop in TV distance from near 1 to near 0 within a window narrow relative to the mixing time—also requires identifying sufficiently unmixed initial laws. The paper justifies comonotonic coupling for this role through a uniform positive-correlation bound under the δ condition (Lemma 3.6). Here it gives a strongly unmixed starting law, easy sampling, and efficient Q₂ computation.
  • Fast Q₂: sort the 3n marginal CDF breakpoints once, in O(n log n). The integral below is then an exact O(n) sweep per genome, with no n × n covariance matrix.
  • Small batches: eight genomes at a time keep working memory O(n). The same equilibrium samples are reused across times; thresholds are chosen on separate training samples, and validation counts use Bonferroni-corrected exact binomial (Beta) tail bounds.
  • No simulation for the upper curve: evaluate the paper's bound directly. Only integer times through log₂ n + 3 are sampled for the lower curve; later lower bounds are set to zero.
The integral identity (short proof)

For a fixed genome x, put gᵢ(u) = 1{Fᵢ⁻¹(u) = xᵢ}/pᵢ(xᵢ) − 1. The code evaluates B = 2ᵗQ₂,ₜ; this positive rescaling only changes the threshold.

B(x) = ½ [ ∫₀¹ (Σᵢ gᵢ(u))² du − Σᵢ (1/pᵢ(xᵢ) − 1) ].

For the site's nonconstant orthonormal functions, completeness gives Σₖ₌₁³ fᵢₖ(a)fᵢₖ(b) = 1{a = b}/pᵢ(a) − 1. Substituting this into the quadratic expansion gives B(x) = Σᵢ<ⱼ ∫₀¹ gᵢ(u)gⱼ(u) du. Expand the square and use ∫₀¹ gᵢ(u)² du = 1/pᵢ(xᵢ) − 1. Each gᵢ is a step function, so the integral is a finite weighted sum over the sorted breakpoints, without numerical quadrature.
